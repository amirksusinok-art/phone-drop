# 📱 Phone Drop — Telegram Mini App

Коллекционная мини-игра в Telegram с виртуальной экономикой, алгоритмической оценкой телефонных узоров и пользовательским рынком с комиссией 5%.

---

## 🌟 Возможности и механики

1. **Каталог Серии 2026**:
   - **10 000 уникальных номеров** по 5 странам: 🇷🇺 Россия (+7), 🇺🇦 Украина (+380), 🇺🇸 США (+1, безопасный диапазон NANPA 555-01XX), 🇹🇷 Турция (+90), 🇨🇳 Китай (+86).
   - Каждый номер существует только в одном экземпляре и сохраняет всю историю находок и передач.
2. **Алгоритм оценки узоров (1–100)**:
   - Распознавание 12 категорий: *Монолит, Двойная пара, Чередование, Зеркальный, Восходящий, Нисходящий, Тройка, Повтор блока, Контрастный, Круглый, Соседние повторы, Смешанный*.
   - Формула ценности: `Score = 100 × (0.45 × Coverage + 0.35 × PatternStrength + 0.20 × Uniqueness)`.
3. **6 уровней редкости**:
   - ⚪ **Обычный** (83%)
   - 🟢 **Необычный** (13%)
   - 🔵 **Редкий** (3%)
   - 🟣 **Эпический** (0.8%)
   - 🟡 **Легендарный** (0.18%)
   - 🌸 **Мифический** (0.02%)
4. **Контейнеры (Дропы)**:
   - **Обычный кейс** (100 Coins) — случайный номер из общего пула.
   - **Национальный кейс** (1 000 Coins) — номер выбранной страны.
   - **Элитный кейс** (10 000 Coins) — только Редкие, Эпические, Легендарные и Мифические.
   - Динамический пересчет актуальных вероятностей в реальном времени.
5. **Продажа системе**:
   - Возврат ненужных номеров за Coins. Номер переходит в свободный пул со статусом `available` (recycled) и сохранением истории.
6. **Рынок с комиссией 5%**:
   - Торговля между реальными игроками. Покупатель платит цену продавца, продавец получает 95%, 5% сгорает в пользу экономики.
7. **Коллекция и расширение слотов**:
   - Начальная вместимость 50 номеров. Расширение за Coins (+25 слотов до 150 мест).
8. **Зал славы (Рейтинги)**:
   - Топ номеров (по стоимости, редкости, категориям).
   - Топ игроков (по балансу Coins, общей стоимости коллекции, числу сделок).
9. **Профиль, Косметика и Альбомы**:
   - Выбор номера для отображения в профиле.
   - Покупка рамок аватара и фонов профиля.
   - Сбор 12 категорий узоров по каждой стране.
10. **Безопасность**:
    - Предупреждение о том, что номера являются исключительно игровыми коллекционными предметами.
    - Автоматическая валидация `initData` через HMAC-SHA256 в Telegram.
    - Встроенный Dev/Demo режим для отладки в браузере вне Telegram.

## 🚀 Быстрый запуск локально

### 1. Установка зависимостей и сборка
```bash
# Установка серверных зависимостей
npm install

# Сборка клиентского интерфейса React/Vite
npm run build
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```env
PORT=3000
BOT_TOKEN=your_telegram_bot_token_here
```
*(Если `BOT_TOKEN` не указан, приложение автоматически запускается в удобном Dev/Demo режиме).*

### 3. Запуск сервера
```bash
npm start
```
Откройте браузер по адресу: **http://localhost:3000**

## 🤖 Подключение к Telegram Bot

1. Откройте в Telegram бота **[@BotFather](https://t.me/BotFather)**.
2. Создайте нового бота: `/newbot` и сохраните полученный **HTTP API Token** (это ваш `BOT_TOKEN`).
3. Создайте Mini App:
   - Отправьте команду `/newapp`.
   - Выберите вашего бота.
   - Введите название (например, `Phone Drop`) и описание.
   - Загрузите иконку (640x360).
   - Введите **Web App URL** (например, ваш URL на Render: `https://phone-drop-xxx.onrender.com`).
   - Задайте короткое имя (short name).
4. Настройте кнопку меню:
   - Введите команду `/setmenubutton`.
   - Выберите бота и введите Web App URL.

## ☁️ Развертывание на Render

### Способ 1: Автоматический (Blueprint `render.yaml`)
1. Зайдите в панель **[Render.com](https://render.com)**.
2. Нажмите **New +** ➔ **Blueprint**.
3. Подключите ваш GitHub репозиторий `phone-drop`.
4. Render автоматически считает конфигурацию из `render.yaml`.
5. Введите переменную `BOT_TOKEN` и нажмите **Apply**.

### Способ 2: Ручное создание Web Service
1. Нажмите **New +** ➔ **Web Service**.
2. Выберите репозиторий `phone-drop`.
3. Укажите параметры:
   - **Environment**: `Node`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
   - **Plan**: `Free`
4. В разделе **Environment Variables** добавьте:
   - `NODE_ENV`: `production`
   - `BOT_TOKEN`: токен вашего бота от BotFather
   - *(Опционально)* `DATABASE_URL`: строка подключения к PostgreSQL (Render Postgres, Neon или Supabase). Если не указана, используется локальная SQLite.
5. Нажмите **Deploy Web Service**.

После завершения деплоя скопируйте предоставленный Render URL (`https://...onrender.com`) и укажите его в BotFather!
